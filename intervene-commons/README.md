# Common library for modules
This is a common library for modules `user-manager`, `pipeline-manager`, `file-handler` & `key-handler`.
E.g. `Spring Webflux`, `Spring Oauth2`, `Open API UI`, `Commons IO` etc.

This module also contains common code for other modules.
`constants`, `dpa`, `DTO`, `Exceptions`, `Open API`, `WebClient`

# Build
Build this module with all other modules otherwise individual build can lead to compilation error. Refer to parent 
`README.md` file.
